# Navonmesh 2024

The official website for **Navonmesh 2024**, the college fest of IMJ Institute of Science & Commerce, Moodlakatte, Kundapura. Visitors can browse events, read the brochure and register.

## Features

- Event pages for **Commerce**, **Cultural** and **IT** events
- Participant registration and login
- Participants dashboard listing registrations
- Downloadable event brochure
- About and developer team pages

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Home page |
| `commerce.html`, `cultural.html`, `it_page.html` | Event categories |
| `reg.html`, `log.html` | Registration and login |
| `dashboard.html` | Participants list |
| `about.html`, `devs.html` | About the fest and the developers |

## Tech stack

HTML5 · CSS3 · JavaScript

## Running

No build step is needed. Open `index.html` in a browser.
